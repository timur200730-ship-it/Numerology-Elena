# Нумерология Елены Осинцевой

Первая версия самостоятельного PWA-приложения.

## Возможности v0.1
- Ввод даты рождения с 01.01.1900.
- Расчёт матрицы 3×3 по правилам из материалов Елены.
- Расчёт количества мужских и женских цифр по подтверждённому правилу урока.
- Контроль обязательного присутствия цифр 1, 2 и 9.
- Печать результата / сохранение в PDF средствами браузера.
- Базовая PWA-оболочка и service worker для офлайн-загрузки приложения.

## Запуск
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
```

## Публикация
Проект рассчитан на Vercel или GitHub Pages с настройкой base path. Для первого запуска рекомендуется Vercel.

## Важно
Показатели «Судьба сегодня», «Воля сегодня», совместимость и авторские трактовки пока не реализованы: их формулы и правила должны быть отдельно подтверждены Еленой. Персональные клиентские страницы, кабинет специалиста и облачное хранение — следующие этапы.
